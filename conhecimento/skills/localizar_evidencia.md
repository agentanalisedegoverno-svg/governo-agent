# Skill: localizar evidência

Para cada critério:

1. procure menções literais e termos equivalentes autorizados;
2. leia o contexto imediato para identificar a atividade realmente executada;
3. copie o menor trecho que preserve o sentido completo;
4. informe a página exibida no documento;
5. não transforme resumo ou inferência em citação.
