# Produtos

Registre aqui conhecimento reutilizavel sobre produtos e servicos: descricao,
arquitetura, implantacao, SLA, suporte, pre-requisitos, limitacoes e regras
comerciais aprovadas.

Cada Markdown de produto deve conter front matter com `status`, `authority`,
`owner`, `version` e `classification`. Propostas comerciais antigas podem servir
como fonte, mas devem ser decompostas em componentes reutilizaveis.
