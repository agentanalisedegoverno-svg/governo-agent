# Exemplos de análises

Este diretório não deve receber atestados reais nem dados pessoais. Exemplos
versionados precisam ser sintéticos ou anonimizados, possuir decisão humana,
identificador da regra aplicada e justificativa da anonimização.

Durante o piloto, os casos rotulados devem permanecer em repositório de dados
controlado. Aqui ficam somente os schemas, manifestos e exemplos sintéticos
aprovados para testes automatizados.
