# Evidencias

Relatorios gerados pelo AI Engineering Governor sao adicionados aqui somente por
branches `ai-governor/*` e Pull Requests. Cada execucao tambem publica seu resumo
no GitHub Actions ou no Pull Request correspondente.

Os pares `.md` e `.json` identificam commit, evento, execucao, achados, fontes,
propostas e validacoes aplicadas. A aprovacao de um PR confirma apenas a decisao
humana registrada naquele diff.
